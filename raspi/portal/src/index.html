03 — RUNBOOK

First-time setup

  1. 01

    Trust the local certificate authority

    Every service here uses a self-signed cert issued by this homelab's own root CA — that's normal for internal-only domains. Grab it below and install it into your device's trust store once, and every *.home.arpa page loads with a normal padlock, no warnings.

    Download rootCA.pem →
  2. 02

    Point your devices at Pi-hole for DNS

    Pi-hole is running as this network's DHCP server, so most devices pick it up automatically on next lease renewal. If yours doesn't, set its DNS server manually to the Pi-hole LAN IP shown in the Pi-hole card below.

  3. 03

    Add local DNS records

    In Pi-hole → Local DNS → DNS Records, map portal.home.arpa, vaultwarden.home.arpa, octoprint.home.arpa, nextcloud.home.arpa, grafana.home.arpa and pihole.home.arpa to this server's LAN IP.

  4. 04

    Set your admin passwords

    Change every default password in .env before first boot — Vaultwarden's admin token, Pi-hole's password, Nextcloud's admin account, and the Grafana admin login all read from there.
